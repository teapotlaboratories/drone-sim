03 Phases are not lanes

Everything shipped so far is Lane A. The phase axis above hides a second one, and the two are easy to conflate: a phase is a capability, a lane is a simulator.

The long pole nobody is holding

Lane C has five tasks, all todo, and nothing currently forces it to start — yet Phase 3 needs it for photoreal scenes and Phase 4 cannot happen without it. The plan rates it High likelihood / Med impact for build fragility: the precompiled Cosys-AirSim Linux plugin targets UE5.2.1, and the UE5.5 branch was a March-2025 pre-release. C-01 is literally "find a commit that builds".

Discovering during Phase 3 that it does not build would be an expensive surprise on the critical path. Proving a build early — C-01 and C-02 alone — de-risks two phases for comparatively little, and can run in parallel with Phase 2 because they share no code.
