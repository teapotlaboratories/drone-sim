Findings fixed

  1. Workspace capacity ran before creation; writability now runs first and is tested.
  2. PX4 must be executable, not merely present.
  3. Unknown port protocols now fail instead of becoming TCP.
  4. The runner now fails closed on artifact infrastructure errors while retaining the smoke exit code.
  5. The workflow reconstructs the canonical repository digest.
  6. An unapproved automatic GHCR-public mutation was removed.
  7. The official ROS base and scoped cache replace redundant stable-layer rebuilds.
  8. PX4/Gazebo now run without ROS vendored library paths; XRCE and ROS commands source the overlay in isolated scopes.
