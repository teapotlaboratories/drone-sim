02 The repo has paid for this three times

Twice before, and again this week

collision_witness.py exists because “an absent witness is UNKNOWN” was written twice, and the two copies disagreed within one commit — one scoring a run PASS that the other failed.

And on 2026-08-17 I told the owner that patches/cosys-airsim/0007 was “applied to nothing” three times. I had checked one script. All three globbed that directory and 0007 matched every one, so the next world conversion would have silently shipped a physics gate that kills bring-up. Caught by review — not by the claim being checkable.

03 One owner

scripts/vendor_patches.sh, sourced by all three: vp_is_unreal_side (the predicate), vp_apply_unreal (apply / already / die, with the remedy sentence as a parameter — the only real difference between the copies) and vp_list, so no caller re-globs. A second glob is a second copy of “which patches exist”.

It matches the diff header, never the prose

0005 mentions the plugin path four times but only twice in a +++ b/ line, so a content grep would misroute a ROS-side patch for merely describing the plugin.

The non-recursive glob is load-bearing

experimental/ is how a patch is parked — 0004 and 0007 live there because the glob does not reach them. Making it recursive would ship both. Now pinned by a test.

04 What running it caught

$applied became unbound

Extracting the loop removed the variable, but callers still used the count — build_blocks.sh to decide whether the compile can be skipped, and convert_world.sh in two further places I had not noticed. Under set -u the build died after patching. Counts are now published as VP_APPLIED/VP_ALREADY, deliberately not squeezed through a return status — that is an exit code, and would be the next person’s mistake.

And two new tests were wrong the same way as one earlier today

One matched the glob inside a comment; the other rejected -r and hit read -r. Substring checks passing for the wrong reason — the identical mistake as the UnrealEditor-C assertion in SIM-33, made twice more within hours. Both now check code rather than text.

The artifact settles it

Both paths exercised — already when present, applied when reversed out and rebuilt. The resulting libUnrealEditor-AirSim.so is md5 20f5430c1a61: byte-identical to the pre-refactor build from two days earlier. Same inputs, same artifact.
