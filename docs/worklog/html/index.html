About these logs

Standing rule

A worklog is a running record, not a final report. Findings, numbers, decisions, and dead ends are appended as they happen, so a resumed session — or a human — can pick up exactly where the work stopped, with the evidence intact.

  • Standalone. Each entry carries its own findings in full — never a "see other doc" pointer.
  • Honest. What failed, what was abandoned, and what remains unverified are recorded alongside what worked.
  • Sourced. Repo facts cite file:line; sim results cite the command and its output; external claims cite the URL or issue.
  • Rendered. Every Markdown worklog has a companion page here, hand-authored and self-contained, with at least one diagram built only from the log's real content.

Markdown sources live in docs/worklog/; these renders live in docs/worklog/html/. The backlog they feed is docs/drone-sim-todo.md.
